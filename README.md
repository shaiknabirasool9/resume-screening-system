# Resume Screening System

An AI-assisted resume screening project that helps organize, filter, and analyze candidate resumes using Python-based data processing and intelligent matching concepts.

## Why this project matters

Recruiters often need to review many resumes against a role description. This project explores how automation and natural-language processing can reduce repetitive screening work while keeping the process structured and explainable.

## Highlights

- Resume data extraction and preprocessing
- Candidate filtering against relevant criteria
- A foundation for NLP-based skill and keyword matching
- Python-first workflow designed for extension and experimentation

## Skills demonstrated

`Python` `NLP` `Data Processing` `Automation` `Machine Learning`
